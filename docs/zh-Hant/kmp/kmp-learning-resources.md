<web-summary>選擇最符合您 KMP 經驗水準的學習教材。</web-summary>

我們彙整了 30 多項必備的 Kotlin Multiplatform (KMP) 和 Compose Multiplatform 學習教材。依技術水準瀏覽，尋找符合您經驗的教學、課程與文章：

🌱 **初階**。透過 JetBrains 和 Google 官方教學學習 KMP 與 Compose 的基礎知識。使用 Room、Ktor 和 SQLDelight 等核心程式庫建構簡單的應用程式。

🌿 **中階**。使用共用 ViewModel、基於 Koin 的相依注入以及整潔架構 (Clean Architecture) 開發真實世界應用程式。透過 JetBrains 及社群講師的課程深入學習。

🌳 **進階**。晉升至用於後端與遊戲開發的全方位 KMP 工程，獲取針對大型、多團隊專案的架構擴充與採納指南。

🧩 **程式庫作者**。建立並發佈可重複使用的 KMP 程式庫。透過官方 JetBrains 工具與範本學習 API 設計、Dokka 文件製作及 Maven 發佈。
