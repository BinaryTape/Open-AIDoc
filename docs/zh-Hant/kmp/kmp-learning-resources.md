<web-summary>選擇最符合你 KMP 經驗水準的學習教材。</web-summary>

我們收集了 30 多個必備的 Kotlin Multiplatform (KMP) 與 Compose Multiplatform 學習教材。你可以依技能等級瀏覽，尋找適合你經驗的教學、課程與文章：

🌱 **初階**。透過 JetBrains 和 Google 官方教學學習 KMP 與 Compose 的基礎知識。使用 Room、Ktor 和 SQLDelight 等核心程式庫建構簡單的應用程式。

🌿 **中階**。使用共用 ViewModel、基於 Koin 的相依注入以及整潔架構（clean architecture）開發真實世界的應用程式。透過 JetBrains 和社群講師的課程深入學習。

🌳 **進階**。邁向適用於後端與遊戲開發的全方位 KMP 工程，並獲得針對大型、多團隊專案擴充架構與採用評估的指引。

🧩 **程式庫作者**。建立並發佈可重複使用的 KMP 程式庫。透過 JetBrains 官方工具與範本學習 API 設計、Dokka 文件製作以及 Maven 發佈。
