# Rescui icons

SVG files copied unchanged (apart from a source comment) from the `svg/` directory of
[`@rescui/icons`](https://www.npmjs.com/package/@rescui/icons) 1.11.0, the icon set of
JetBrains' Rescui design system. They are licensed under the Apache License 2.0; see
`LICENSE.txt` in this directory.

| File | Used for |
|---|---|
| `info_24.svg` | Writerside `note` callouts |
| `read_24.svg` | Writerside `tip` callouts |
| `warning_24.svg` | Writerside `warning` callouts |
| `down_24.svg` | Collapsible code blocks |
| `arrow-left_24.svg`, `arrow-right_24.svg`, `download_24.svg` | Writerside button links |

The package also contains Kotlin, Ktor and JetBrains logos. Those are trademarks, not
covered by the Apache license; do not copy them here.
