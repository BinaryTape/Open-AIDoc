# Rescui icons

SVG files copied unchanged (apart from a source comment) from the `svg/` directory of
[`@rescui/icons`](https://www.npmjs.com/package/@rescui/icons), the icon set of
JetBrains' Rescui design system. They are licensed under the Apache License 2.0; see
`LICENSE.txt` in this directory (the same text in both versions used).

| File | From | Used for |
|---|---|---|
| `info_24.svg` | 1.11.0 | Writerside `note` callouts |
| `read_24.svg` | 1.11.0 | Writerside `tip` callouts |
| `warning_24.svg` | 1.11.0 | Writerside `warning` callouts |
| `down_24.svg` | 1.11.0 | Collapsible code blocks |
| `arrow-left_24.svg`, `arrow-right_24.svg`, `download_24.svg` | 0.16.17 | Writerside button links |
| `plus_24.svg` | 0.16.17 | Collapsible sections (⊕; turned 45° when open, ⊗) |

kotlinlang.org draws its buttons with the 0.16 icons: thin, square-ended arrows, which
1.0 redrew rounded and heavier. 0.16.17, the last 0.x release, names its files without a
size (`arrow-right.svg`); they are 24 px and keep the `_24` name here.

The package also contains Kotlin, Ktor and JetBrains logos. Those are trademarks, not
covered by the Apache license; do not copy them here.
