## AI 도구를 활용한 개발 {id="develop-with-ai-tools"}

AI 기반 개발 도구는 Kotlin 코드를 작성, 테스트 및 유지 관리하는 데 도움을 줍니다.

Kotlin은 IDE 연동, 재사용 가능한 AI skills, Claude Code 및 OpenAI Codex와 같은 서드파티 AI 도구를 통해 AI 지원 개발을 지원합니다.

이러한 도구에 대한 개요와 사용 방법은 [AI 기반 Kotlin 개발](ai-for-development.md)을 참조하세요.

> 어떤 AI 에이전트를 사용해야 할지 잘 모르겠다면, [Kotlin Benchmark](https://kotlinlang.org/benchmark/)를 확인하여 다양한 에이전트가 Kotlin 개발 작업에서 어떤 성능을 보이는지 비교해 보세요.

### Kotlin AI skills {id="kotlin-ai-skills"}

Kotlin AI skills는 AI 에이전트가 Kotlin 개발 작업을 일관되게 완료할 수 있도록 돕는 재사용 가능한 작업별 지침(instruction)입니다.

호환되는 AI 에이전트에 AI skills를 제공하여 다음과 같은 작업을 수행할 수 있습니다.

* Kotlin 코드 설명
* 테스트 작성
* API 마이그레이션
* Kotlin 모범 사례 적용

자세한 내용은 [](kotlin-ai-skills.md)를 참조하세요.
