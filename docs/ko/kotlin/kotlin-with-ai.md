## AI 도구로 개발하기 {id="develop-with-ai-tools"}

AI 기반 개발 도구를 활용하면 Kotlin 코드를 작성, 테스트, 유지보수하는 데 도움을 받을 수 있습니다.

Kotlin은 IDE 연동, 재사용 가능한 AI 스킬(skills), 그리고 Claude Code, OpenAI Codex 등과 같은 서드파티 AI 도구를 통한 AI 보조 개발을 지원합니다.

이러한 도구에 대한 개요와 사용 방법은 [AI 기반 Kotlin 개발](ai-for-development.md)을 참고하세요.

### Kotlin AI 스킬 {id="kotlin-ai-skills"}

Kotlin AI 스킬은 AI 에이전트가 Kotlin 개발 작업을 일관되게 수행할 수 있도록 돕는 재사용 가능한 작업별 지침(instruction)입니다.

호환되는 AI 에이전트에 AI 스킬을 제공하여 다음과 같은 작업을 수행할 수 있습니다:

* Kotlin 코드 설명
* 테스트 작성
* API 마이그레이션
* Kotlin 모범 사례 적용

자세한 내용은 [](kotlin-ai-skills.md)를 참고하세요.
